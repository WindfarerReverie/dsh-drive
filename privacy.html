Privacy policy

Last updated: 24 November 2026

DSH Drive is used only by its owner, with the owner's own Google account.

  • What it accesses: files in the owner's Google Drive, through the Google Drive API, after the owner signs in and grants access.
  • Where data goes: file contents are read by the owner's desktop application on the owner's own computer. DSH Drive runs no server of its own and does not store Google user data anywhere else.
  • Sharing: Google user data is not sold, not shared with third parties, and not used for advertising.
  • Revoking access: access can be removed at any time at myaccount.google.com/permissions.

DSH Drive's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions: open an issue on this project's GitHub page.
